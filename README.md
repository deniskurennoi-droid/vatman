# Ватман

Бесконечная доска в браузере: стикеры, фигуры, стрелки, рамки, перо, картинки.
Один файл `index.html` — без сборки, без зависимостей, без сервера.
Доска сама сохраняется в браузере, в котором её открыли.

**Открыть:** https://deniskurennoi-droid.github.io/vatman/

## Что умеет

- Бесконечный холст: панорама колесом, пробелом или двумя пальцами; зум Ctrl+колесом и щипком.
- Стикеры, текст, прямоугольник, овал, ромб, треугольник, перо, линии и стрелки, рамки, картинки.
- Стрелки прилипают к объектам и тянутся за ними.
- Выделение, перемещение, растягивание, поворот; прилипание к соседям с направляющими.
- Рамка тащит за собой всё, что внутри.
- История Ctrl+Z, контекстное меню, миникарта, шаблоны, светлая и тёмная тема.
- Экспорт PNG и SVG в буфер обмена, полная копия доски в JSON.

Полный список горячих клавиш — кнопка «?» в правом верхнем углу.

## Откуда берётся этот файл

Исходник живёт в личном репозитории настроек, в `apps/vatman/index.html`.
Здесь лежит его копия — только она публичная. Обновить копию:

```powershell
Copy-Item C:\Users\Admin\.claude\apps\vatman\index.html C:\Users\Admin\vatman-site\index.html -Force
```

Потом обычный `git add -A; git commit; git push` — GitHub Pages подхватит новую версию за минуту.
